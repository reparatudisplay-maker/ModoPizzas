# Estándar UI

- Una acción principal por pantalla.
- Etiquetas visibles.
- Errores junto al campo.
- Estados con texto e icono además de color.
- Controles táctiles cómodos.
- Formato COP consistente.
- Unidades visibles.
- Móvil y escritorio.
- Carga, vacío, error y deshabilitado.

## Modales con formularios largos

- Mantener header y footer fijos.
- El contenido central debe tener scroll interno.
- El footer debe estar fuera del área con scroll, al final del modal, sin superponerse sobre campos.
- El footer debe usar fondo sólido, borde superior y z-index sobre el contenido.
- Dejar espacio inferior suficiente para que el último campo, validaciones y autocompletados no queden tapados.
- El último campo debe poder desplazarse hasta quedar completamente visible antes del footer.
